使用說明

把程式貼進來執行一次，之後就能一步一步看它每一行做了什麼：變數怎麼變、資料結構長什麼樣子。在主畫面上，滑鼠停在任何圖例或標記上，也會跳出下面名詞表裡的說明。

快速開始

  1. 右上角 Language 選 Python 或 C++。
  2. 把程式貼進 Source code。
  3. 把輸入資料貼進 Test data（stdin），就是平常從鍵盤輸入的內容。
  4. 按 Run（約 1–10 秒，C++ 比較慢）。
  5. 按 → 或 › 往下一步，← 退回上一步，Space 自動播放。要改程式就按 Edit code。

每一步怎麼看

  • 黃色那一行還沒執行，是「接下來要執行的這一行」。
  • 視覺化圖畫的是黃色那一行執行完之後的樣子。例如停在 vis[v] = true 時，v 已經打勾。
  • Variables 列出現在的值；這一行會改的值寫成 7 -> 8（現在 → 執行後）。
  • stdout 是到這一步為止程式印出的內容。

畫面區塊

Source code
程式碼。執行後黃色標出目前這一行；左側是行號。
Test data
stdin 輸入資料。
視覺化圖（上方右側）
依程式的樣子自動選畫法：長條圖、格子、圖（節點與邊）、並查集、遞迴樹、線段樹。用 View 選單可以換畫法或指定要畫的變數。
Variables
目前的變數。左邊是單一值，右邊是陣列和容器。已經畫在圖上的變數不會在這裡重複出現；把圖收起來（Hide）就會回到這裡。
stdout
程式輸出。
時間軸（最下方）
拖曳滑桿可以跳到任何一步。|‹、›| 跳到目前迴圈的前後。右邊的速度選單控制自動播放速度。
Hide 與分隔線
每個區塊都能收起來；拖曳區塊之間的分隔線可以調整大小，雙擊分隔線恢復預設。

錯誤與限制

  • RE：執行錯誤（除以零、陣列越界、assert 失敗……）。停在出錯的那一行，前面的步驟都看得到。
  • TLE：超過時間（Python 3 秒、C++ 10 秒）或超過 5000 步就停下來，前面的步驟仍然保留。
  • 編譯或語法錯誤：錯誤的那一行會在程式碼裡標紅，訊息顯示在上方。
  • Python 只能 import sys，也不能用 open、eval 等函式。
  • C++ 需要電腦上有 g++ 和 gdb；unordered_map 等容器只會顯示「contents not decoded」。
  • 很長的陣列只讀取前 50 項，圖上會寫「0–49 of 80 items」。
  • 演算法名稱是從程式碼猜的（「guessed from the code」），可能猜錯。
