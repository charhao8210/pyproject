使用說明

把程式貼進來執行一次，之後就能一步一步看它每一行做了什麼：變數怎麼變、資料結構長什麼樣子。在主畫面上，滑鼠停在任何圖例或標記上，也會跳出下面名詞表裡的說明。

快速開始

  1. 右上角語言選單選 Python 或 C++。
  2. 把程式貼進 程式碼，或用 選擇範例 載入本機範例與測試資料。
  3. 把輸入資料貼進 輸入，就是平常從鍵盤輸入的內容。
  4. 按 執行（一般約 1–10 秒，提高擷取設定時可能需要更久）。
  5. 按 → 或 › 往下一步，← 退回上一步，Space 自動播放。要改程式就按 編輯。

每一步怎麼看

  • 黃色那一行還沒執行，是「接下來要執行的這一行」。
  • 視覺化圖會呈現能從追蹤確認的本行效果。例如停在 vis[v] = true 時，已記錄的寫入會讓 v 打勾。未擷取的內容會保持未知。
  • 變數 列出現在的值；這一行會改的值寫成 7 -> 8（現在 → 執行後）。
  • 輸出 是到這一步為止程式印出的內容。

聚焦與跟隨位置

聚焦（Focus） 預設開啟，讓當下讀取、寫入與相關路徑更醒目。DFS／遞迴顯示目前呼叫路徑，已完成分支折疊成摘要。展開摘要可查看已記錄的呼叫，點選呼叫可跳到進入或最後步驟；呼叫鏈 只看目前呼叫堆疊。關閉聚焦可看完整的可用資料。

跟隨（Follow） 會保持目前節點、格子或分頁可見；想固定位置自行檢查時可取消勾選。DP 的一行摘要顯示讀取或變更；公式、候選值、依賴和範圍可展開查看。圖聚焦相關鄰居與佇列，排序保持固定比例，並查集顯示父鏈，線段樹可顯示查詢覆蓋與已擷取的 lazy tag。

「已返回」只代表函式已返回，不會被自動當成「剪枝」或「找到解」。分頁與折疊只改變觀看方式，不會改變程式或補出未記錄的資料。

跳步模式也套用到 播放。滑桿仍可查看個別快照，←／→ 移動，Space 播放或暫停。

修正模式與變數配對

  1. 完成一次執行後，開啟 ⚙ 顯示設定。
  2. 選擇 演算法模式，再指定主要資料、索引等變數角色；留在 自動 可使用自動辨識。
  3. 按 套用，用目前的程式與輸入重新執行。按 Escape 可關閉設定並回到齒輪按鈕。

例如滑動視窗配對「主要資料」、「左界」、「右界」、「總和／統計」；圖配對佇列、距離／入度與父節點；字串比對配對文字、模式字串與 Prefix table；線段樹可指定 Lazy tag 和查詢左右界。配對是已記錄的變數名稱，不是監看運算式；模式仍需要相容的資料形狀與程式結構。

擷取範圍與未知資料

「每個容器擷取」可選 50／100／200／500 項，預設 50。Python「巢狀深度」可選 2／3／4／6／8 層，預設 4；API 支援深度 2–8。C++ 一維容器也使用項目上限，表格最多 30 列 × 40 欄，不使用 Python 深度設定。

資料超出擷取範圍時會標示截斷或未知；提高上限後套用設定，會重新執行並收集新快照。舊快照沒有收集的值無法藉由展開或分頁補出。未知格子不會被假設為零；離開作用域的資料會標示最後已知狀態。

函式庫內部的 heapq sift、內建排序比較與 C++ STL 操作不會被重建成假的逐步動畫。只有已記錄的使用者程式操作與可確認的狀態變化才會顯示。

錯誤與限制

  • RE：執行錯誤（除以零、陣列越界、assert 失敗……）。停在出錯的那一行，前面的步驟都看得到。
  • TLE：超過時間（Python 預設 3 秒，提高擷取設定可增加至最多 15 秒；C++ 10 秒）或超過 5000 步就停下來，前面的步驟仍然保留。
  • 編譯或語法錯誤：錯誤的那一行會在程式碼裡標紅，訊息顯示在上方。
  • Python 支援受限的 sys.stdin、公開的 heapq／bisect 操作、collections.deque/defaultdict/Counter 與 math 數學函式／常數。可匯入模組或明確成員並使用別名；不允許其他模組、私有成員、萬用字元、相對匯入與 open／eval。
  • C++ 需要 GNU g++ 和 gdb，容器解析使用 libstdc++。Windows 可使用 PATH 中的 MSYS2 UCRT64 工具，或專案內完整的 .tools/msys64/ucrt64 工具鏈。支援的 vector、deque、預設 queue／stack、priority_queue、set／map 可解碼；unordered_map 等不支援的容器或元素仍顯示「contents not decoded」。
  • 容器預設擷取前 50 項，可依上述設定調整。很大的樹也有繪製上限；介面會標示顯示範圍。
  • 每種畫法先準備前 6 個變數；View 的變數選單裡標「(runs again)」的，選了之後會用同一份程式和輸入重跑一次再顯示（約 1–10 秒）。
  • 圖的邊是有向還是無向是從資料猜的；猜錯時用圖上方的方向選單改。
  • 設定內的演算法名稱是從程式碼推測（「自動推測」），可能猜錯；圖的短標題只表示目前畫出的資料類型。
